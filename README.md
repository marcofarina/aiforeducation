# AI for Education

Dispense dei corsi di formazione sull’intelligenza artificiale per i docenti dell’I.I.S. J. C.
Maxwell: un ripasso dei fondamenti e un capitolo per ogni incontro dei corsi base, intermedio e
avanzato.

Il sito è costruito con [VitePress](https://vitepress.dev) a partire dai file Markdown in
`docs/` e pubblicato su GitHub Pages. Per lavorarci in locale servono Node.js 22 o successivo e
due comandi: `npm install`, poi `npm run dev`. Le istruzioni per chi modifica il sito, persone
o agenti, stanno in [`AGENTS.md`](AGENTS.md).
